# Multi-modal Vision Assistant 
An Artificial Intelligence (AI) app that assists people with visual impairments understand their surroundings through real-time object recognition, OCR, and voice output.

# Features 
- Real-time Object Detection (YOLOv8)
- Text Recognition (EasyOCR) 
- Scene Comprehension 
- Voice Output (Text-to-Speech) 
- Multi-modality (Vision + Language + Speech)

# System Architecture
Camera Input ➡ Preprocessing ➡ Object Detection + OCR ➡ Scene Comprehension ➡ Text Generation ➡ Speech Output 

# Technology Used 
- Python 
- Flask 
- PyTorch
- OpenCV
- YOLOv8 
- EasyOCR
